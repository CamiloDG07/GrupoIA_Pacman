De acuerdo con la guia de laboratorio, al finalizar este trabajo el grupo estara en capacidad de:

\begin{itemize}
    \item identificar los componentes de un problema de busqueda;
    \item diferenciar busqueda no informada e informada;
    \item implementar el algoritmo A* sobre el entorno Pac-Man;
    \item utilizar funciones heuristicas (nula, Manhattan, Euclidiana y disenadas por el grupo);
    \item comparar heuristicas Manhattan y Euclidiana en terminos de costo, nodos expandidos y tiempo;
    \item analizar la admisibilidad y consistencia de las heuristicas propuestas;
    \item disenar una heuristica propia para el problema de las esquinas o el de recoleccion de alimentos;
    \item evaluar experimentalmente la eficiencia de cada estrategia de busqueda implementada.
\end{itemize}
